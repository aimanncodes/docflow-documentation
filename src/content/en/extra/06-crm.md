## Setting up CRM

1. Define [sales stages and lost reasons](/crm/crm-settings).
2. Set lead sources: Website, Exhibition, Referral, WhatsApp, Walk-in, Cold Call.
3. Set up [assignment rules](/framework/automation) to share leads among the team.
4. Connect email and, if available, telephony and WhatsApp ([communication](/crm/communication)).
5. Add a [web form](/website/web-forms) to your website for enquiries.

## Key fields

| Field | What it does |
| --- | --- |
| Source | Where the lead came from; used in campaign reports |
| Lead Owner | The salesperson responsible |
| Status | Lead, Open, Replied, Opportunity, Interested, Converted, Do Not Contact |
| Qualification Status | Unqualified, In Process, Qualified |
| Territory / Industry | For routing and reporting |

## Common problems

:::details Duplicate leads from the website
Switch off lead duplication by email in [CRM settings](/crm/crm-settings), so a repeat enquiry is added to the existing lead.
:::
