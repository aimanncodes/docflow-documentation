## Setting up Projects

1. Create [project types and activity types](/projects/project-settings) with costing and billing rates.
2. Build [project templates](/projects/project-setup) for repeat work.
3. Make the project field mandatory on purchases and stock entries.
4. Set up [milestone payment terms](/projects/milestone-billing).

See the [fit-out project walkthrough](/guides/fit-out-project) for one complete example.

## Key fields

| Field | What it does |
| --- | --- |
| Status | Open, Completed or Cancelled |
| Priority | For sorting and dashboards |
| % Complete Method | Manual, task completion, task progress or task weight |
| Cost Centre | Where project costs post by default |
| Sales Order | Links revenue to the project |
| Collect Progress | Sends regular update requests |

## Behind the scenes

Timesheets do not post to the ledger by themselves. Their costing amount is added to the project's labour cost for reporting; actual salary cost is posted by payroll. Billing amounts become revenue only when invoiced.
