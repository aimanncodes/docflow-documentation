## Setting up Quality

1. Write your key [quality procedures](/quality/goals-reviews).
2. Create inspection templates for incoming, in-process and final checks.
3. Mark items that need inspection.
4. Set measurable goals and a review schedule.
5. Train storekeepers and supervisors to record inspections and non-conformances.

## Key fields

| Field | What it does |
| --- | --- |
| Inspection Type | Incoming, Outgoing or In Process |
| Reference Type and Name | The receipt, delivery or job card inspected |
| Sample Size | How many units were checked |
| Readings | One row per parameter with values and status |
| Status | Accepted or Rejected overall |
| Inspected By | The person responsible |

## Common problems

:::details The receipt still asks for an inspection
The inspection must be submitted, not just saved, and must reference the same receipt and item row.
:::
