## إعداد الجودة

1. اكتب [إجراءات الجودة](/quality/goals-reviews) الرئيسية.
2. أنشئ قوالب الفحص للوارد وأثناء الإنتاج والنهائي.
3. حدد الأصناف التي تحتاج إلى فحص.
4. عيّن أهدافاً قابلة للقياس وجدولاً للمراجعة.
5. درّب أمناء المستودعات والمشرفين على تسجيل الفحوصات وحالات عدم المطابقة.

## الحقول الرئيسية

| الحقل | وظيفته |
| --- | --- |
| نوع الفحص | وارد أو صادر أو أثناء الإنتاج |
| نوع المرجع واسمه | الإيصال أو التسليم أو بطاقة العمل المفحوصة |
| حجم العينة | عدد الوحدات المفحوصة |
| القراءات | صف لكل معيار بالقيم والحالة |
| الحالة | مقبول أو مرفوض إجمالاً |
| الفاحص | الشخص المسؤول |

## مشكلات شائعة

:::details ما زال الإيصال يطلب فحصاً
يجب اعتماد الفحص لا حفظه فقط، وأن يشير إلى الإيصال وصف الصنف نفسيهما.
:::
