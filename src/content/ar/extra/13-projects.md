## إعداد المشاريع

1. أنشئ [أنواع المشاريع والأنشطة](/projects/project-settings) بأسعار التكلفة والفوترة.
2. ابنِ [قوالب مشاريع](/projects/project-setup) للأعمال المتكررة.
3. اجعل حقل المشروع إلزامياً في المشتريات وقيود المخزون.
4. أعدّ [شروط الدفع حسب المراحل](/projects/milestone-billing).

راجع [دليل مشروع التشطيب](/guides/fit-out-project) لمثال كامل.

## الحقول الرئيسية

| الحقل | وظيفته |
| --- | --- |
| الحالة | مفتوح أو مكتمل أو ملغى |
| الأولوية | للترتيب ولوحات المعلومات |
| طريقة احتساب الإنجاز | يدوي أو إكمال المهام أو تقدم المهام أو وزن المهام |
| مركز التكلفة | حيث تُرحَّل تكاليف المشروع افتراضياً |
| أمر البيع | يربط الإيراد بالمشروع |
| جمع التقدم | يرسل طلبات تحديث دورية |

## ما يحدث خلف الكواليس

لا ترحّل سجلات الوقت إلى الأستاذ بنفسها، بل يُضاف مبلغ تكلفتها إلى تكلفة عمالة المشروع للتقارير، وتُرحَّل تكلفة الرواتب الفعلية عبر الرواتب، ولا تصبح مبالغ الفوترة إيراداً إلا عند الفوترة.
