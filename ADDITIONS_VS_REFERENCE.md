# Additions compared with the reference documentation

**Internal document, not published on the website.** It lists what the DocFlow manual adds beyond the reference documentation it was modelled on (the ERPNext user manual), so you can review each addition and decide whether to build it and keep it.

How to read it:

- **Status in manual** shows whether the page is labelled Planned. "Partly planned" means some sections or steps on the page carry a Planned label. See `PLANNED_FEATURES.md` and the Planned features page (`/en/planned`).
- Links are site paths. Open them on the live site or at `http://localhost:5288`.
- This is my own classification, made from the reference's list of topics. The wording of every page is original; the reference was used only as a checklist of features.

## Changes that apply to every page

| Change | Where |
| --- | --- |
| UAE examples: AED amounts, UAE cities, the fictional sample companies (Al Waha Trading, Saqr Steel, Lulu Pearl Foods, Rimal Facilities) | Throughout |
| "UAE specific" boxes explaining FTA, MOHRE and other UAE rules | Most pages |
| Full Arabic translation with right-to-left layout | Every page |
| Numbered figures with screenshot folders | Every page |
| Module structure follows DocFlow, not the reference (for example Organisation, UAE Compliance, HR & Payroll, End-to-end guides) | Sidebar |
